# 输入

作者向 Claude 提供输入文件的地方：论文、笔记、截图、手稿、数据、视频链接等，格式不限。

## 智能体如何处理

- 每次工作开始时，检查本目录是否有新文件。
- 读取后，按内容分流：
  - 作者的想法 → 在作者要求时整理到 `我的想法/README.md`，忠实转述；
  - 理论、实验、文章等资料 → 提取到 `灵感库/`，在条目来源中注明"作者提供：文件名"；
  - 需要回应的问题或任务 → 处理后把结果放进 `Claude想法/输出/`。
- 不修改原始文件的内容。
- 处理完成后，按作者要求清空本目录：论文等需要保留的原始文件移到 `参考文献/论文/`，并用"第一作者年份-简称"重命名；本说明文件保留。

## 建议

- 文件名尽量带日期和简短说明，例如 `20261126-关于真空的手稿.pdf`。
- 需要 Claude 做特定处理时，可以附一个同名的 `.md` 说明文件，或直接在对话中说明。
