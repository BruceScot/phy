# 我的想法

本目录由 **作者** 撰写，记录作者的想法和点子。它们会随着时间持续变化，是项目运行中的重要方向指引。

- 智能体每次工作前会阅读本目录，优先考虑与这里的想法相关的方向。
- 智能体不会修改作者的想法；只在作者要求时代为记录，记录时忠实转述。
- 输入文件请放在 [输入/](输入/) 中，智能体会读取并处理，见该目录说明。
- 智能体对某个想法有不同意见时，写在 [Claude想法/](../Claude想法/) 中，并注明针对的是哪一条。

## 格式

可以按自己习惯写，不必拘泥格式。如果想便于引用，可以每条一个编号：

```markdown
## M001 标题（YYYY-MM-DD）

想法内容……

- 状态：活跃 / 已调整 / 已放弃
- 相关：Lxxx, Cxxx
```

想法调整时，建议保留旧版本并注明变化，而不是直接删除，这样方向的演变过程也有记录。
