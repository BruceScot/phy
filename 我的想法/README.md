- 智能体每次工作前会阅读本目录，优先考虑与这里的想法相关的方向。
- 智能体不会修改作者的想法；只在作者要求时代为记录，记录时忠实转述。

## M001 量子力学之下可能有更底层的理论（2026-11-26）

> 以下由 Claude 根据作者在对话中的表述代为记录。

作者不认同"在已检验区域 QED 几乎没有留下修改余地"（C001）的判断，理由是：

1. 广义相对论与量子力学不相容；
2. 电磁力为什么比引力大这么多，原因不明；
3. 希格斯机制如何解释中微子质量，尚不清楚；
4. 作者倾向于认为量子力学偏向一种描述方式，背后的理论还有待发现。QED 更像是一种精度较高的规律性描述和解释，但不排除有更底层、更精确的解释和描述。

补充两点：

1. 作者认同 Claude 的观点：底层理论和 QED 的关系，会像广义相对论和牛顿引力的关系一样。
2. 数学结构在适用范围内正确，不代表理论基础和模型正确。

- 状态：活跃
- 相关：C001、C005；L015–L025

## M002 不认可虚光子理论，但认可 QED；过程必须有确定的时间（2026-11-28）

> 以下由 Claude 根据作者在对话中的表述代为记录。

作者不认可虚光子理论，但这不代表不认可 QED。

起因是 Claude 说"静态力对应的虚光子没有确定的飞行时间"。作者认为：没有时间就没有过程，这相当于把动量的传递过程变成了瞬时作用，然后就不需要解释这个瞬时了。

- 状态：活跃
- 相关：E20261128-01（近场推迟课题）；L084、L108–L110；Claude想法/输出/20261128-场如何传递动量.md
