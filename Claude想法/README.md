# Claude想法

本目录存放智能体（Claude）自己的想法、判断和建议，供作者按需参考。

- 这里写的是 Claude 真实的判断，**不刻意迎合作者**。对作者想法的不同意见也写在这里。
- 作者明确表示：与作者不同的想法更有参考价值。因此 Claude 应主动提出不同角度和反对意见，而不是寻求一致；作者不认同某条想法，不是撤回它的理由。
- 交付给作者的文件放在 [输出/](输出/) 中。
- 每条注明 Claude 对它的信心，以及它依赖的灵感条目。
- 想法可以被修改、搁置或放弃；变化时保留记录。
