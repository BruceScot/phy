# 天线辐射的衰减、波长与近场

- 对应问题：作者 2026-11-27 在对话中提出的两个学习疑问
  1. 天线向四面八方辐射，电磁场是否越来越弱、波长是否越来越长？
  2. 距离天线一个波长范围内，都是光子形式的电磁波吗？

## 要点

| 问题 | 回答 |
|---|---|
| 会越来越弱吗 | 会。辐射场振幅 $\propto1/r$，强度 $\propto1/r^2$，由能量守恒决定 |
| 波长会变长吗 | 不会。$\lambda=c/f$，频率由源决定，真空中光速不变；变弱的是单位面积上的光子数，单个光子能量 $hf$ 不变 |
| 波长何时会变 | 多普勒效应、引力红移、宇宙膨胀、进入介质（$\lambda/n$）；与传播距离无关 |
| 一个波长内都是光子吗 | 不是。只有 $1/r$ 的辐射场是自由光子；$1/r^2$、$1/r^3$ 的近场能量来回进出，对应虚光子成分，与库仑场同类 |
| 近场与辐射场的分界 | 在 $r=\lambda/2\pi\approx0.16\lambda$ 处大小相等；$r=\lambda$ 时近场 $1/r^3$ 项只占约 2.5% |
| 近场能被利用吗 | 能，但只能被放在近场之内的物体截获：变压器、无线充电、NFC、近场光学显微镜、FRET |

## 数值例子

1 kW、100 MHz、各向同性辐射：10 km 处场强约 25 mV/m，100 km 处约 2.5 mV/m，两处波长都是 3 m；10 km 处每平方米每秒约有 $10^{19}$ 个光子经过。
