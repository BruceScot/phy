# 方法

方法是整个研究过程中 **始终要遵循的做法**。原则（见 [原则](../原则/README.md)）说明什么是好的结论；方法说明怎样得到结论。

## 一、鼓励创造性的开放思考

本项目明确希望智能体发挥创造性：

- **可以**提出大胆、非常规、暂时缺乏证据的猜想，可以质疑主流理论，可以把看似无关的领域联系起来。
- **可以**在没有被要求时主动提出想法，记录在 [Claude想法/](../Claude想法/)。
- **不需要**迎合作者的观点。作者的想法是重要指引，但发现问题时应直接指出，并给出理由。
- **必须**标明每个论断的性质：是已确立的事实、合理推断，还是猜想。创造性与诚实并不冲突。

## 二、两种研究模式

研究分为 **理论探索** 和 **理论构建** 两种模式，规则见 [研究模式/](../研究模式/README.md)。每次工作开始时先明确当前处于哪种模式。

## 三、灵感组装的手法

在理论探索模式中，从 [灵感库](../灵感库/索引.md) 中提取条目，用以下手法组装和改造：

| 手法 | 做法 | 例子 |
|---|---|---|
| 组合 | 把两个条目的机制放到同一个体系中 | 腔真空修饰（L010）+ 光电子延迟（L003）：腔是否改变光电子的发射时间？ |
| 类比 | 把一个领域的结构搬到另一个领域 | 狄拉克海（L013）↔ 凝聚态满价带与空穴 |
| 反转 | 把一个条目的结论或假设反过来 | 若真空涨落不是"真实"的，哪些现象需要重新解释？ |
| 推到极限 | 把某个参数推到极端 | 场强推到 Ritus–Narozhny 区（L007） |
| 去掉假设 | 找出一个理论的隐含假设并去掉它 | 去掉"恒定场"假设后，强场微扰论的结论是否改变？ |
| 借失败 | 研究一个被否定的理论在哪里失败 | 随机电动力学（L006）在哪里失败，就说明哪里需要真正的量子性 |
| 换测量 | 把同一个问题换一种测量方式 | 隧穿时间（L012）：attoclock 与 Larmor 钟给出不同的"时间" |

## 四、证据与来源

1. 每个论断要能追溯到来源；没有来源的，标"待核实"。
2. 引用原始论文和权威综述，尽量少用二手转述。
3. 引用原文只摘短句，其余用自己的话概括。
4. 完整文献条目放入 [参考文献/references.bib](../参考文献/references.bib)。

## 五、推导与计算的检验

理论构建模式中，每个推导结果都要通过以下检验：

1. **量纲检查**：结果的量纲正确。
2. **极限检查**：在已知极限下（弱场、非相对论、自由空间等）还原为已知结果。
3. **已知结果复现**：方法首先能复现一个已知的结果。
4. **独立验证**：重要结果用另一种方法（解析与数值、两种近似、符号计算）独立验证。
5. **代码可复现**：数值计算的代码放进仓库，注明运行方法和依赖。

## 六、自我批评

每个猜想或结论提出后，至少从一个反方向审视：**如果它是错的，最可能错在哪里？** 把这一审视写下来，和结论放在一起。

## 七、记录失败

没有走通的思路、被否定的猜想，同样要记录在对应的探索记录中，并写明失败原因。它们是之后的灵感来源，也能避免重复。

## 八、作者与智能体的分工

- `我的想法/` 由作者撰写，是方向指引。智能体只在作者要求时代为记录，记录时忠实转述，不改写原意。
- `Claude想法/` 由智能体撰写，作者按需参考。
- 架构和内容可以随时调整；涉及目标、原则或结构的重大变更，先征求作者意见。
