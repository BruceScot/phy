# 灵感库

灵感库收录 **所有与研究内容相关的理论、实验、猜想和观点**，不论是否被证实，也不论来自教科书、前沿论文、历史文献、科普视频还是民间科学爱好者（民科）。

它的用途是：在研究运行中，随时从这里提取可能适用的想法，进行 **任意的组装和改造**。因此每一条都要写清两件事：**它本身是什么**，以及 **能从中借走什么**。

- 全部条目：[条目/](条目/)
- 总表：[索引.md](索引.md)，由 `python3 工具/生成索引.py` 自动生成
- 新条目模板：[模板.md](模板.md)
- 定时补充的规则：[补充规程.md](补充规程.md)；运行记录见 [补充日志.md](补充日志.md)

## 标注字段

| 字段 | 取值 | 说明 |
|---|---|---|
| 类型 | 理论 / 实验 / 猜想 / 观点 | "观点"用于科普和民科中不成体系的说法 |
| 状态 | 已证实 / 部分证实 / 未证实 / 有争议 / 已被取代 / 已否定 | 学界对它的判断 |
| 来源 | 经典 / 前沿 / 历史 / 科普 / 民科 | 信息从哪里来 |
| 适用范围 | 自由文本 | 在什么条件、尺度、体系下成立或被讨论；也写明在哪里失效 |
| 置信度 | 1–5 | 内容本身为真的可信程度 |
| 可参考性 | 1–5 | 能从中借鉴出有用思路、方法、类比的程度 |
| 标签 | 逗号分隔的关键词 | 用于检索和组装 |
| 录入 | 日期 · 已核实/待核实 | 核实指已对照原始来源 |

### 置信度

| 分 | 含义 |
|---|---|
| 5 | 多个独立实验高精度验证，理论自洽 |
| 4 | 有可靠实验或严格推导支持，细节仍有讨论 |
| 3 | 有部分证据，精度、重复性或解释有争议 |
| 2 | 只有理论论证或间接证据 |
| 1 | 与已确立结果冲突，或已被否定，或缺乏任何论证 |

### 可参考性

| 分 | 含义 |
|---|---|
| 5 | 能直接引出新问题、新方法或新的研究方向 |
| 4 | 有明确可迁移的思路或类比 |
| 3 | 有一定参考价值，主要作为背景 |
| 2 | 只有零星可用之处 |
| 1 | 暂时看不出可借鉴之处 |

> **置信度和可参考性彼此独立。** 已被否定的理论可能可参考性很高（例如随机电动力学恰好标出了量子性的边界）；高度确立的理论也可能已无新意可挖。筛选时两者都要看，**任何指标都不作为排除条件**。

## 收录原则

1. **不预先排除**：民科、被否定的旧理论、科普中的类比都可以收录。
2. **如实记录，再加评注**：先忠实转述原说法，再在"依据与争议"中指出它与已确立物理的冲突。
3. **借鉴点必须具体**：写出可以借走的那个思路、方法、可观测量或类比，而不只是"有启发"。
4. **来源可追溯**：注明出处；视频注明标题、作者、链接和时间点。
5. **去重**：录入前先查索引和标签；已有条目时补充到原条目，而不是新建。
