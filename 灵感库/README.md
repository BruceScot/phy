# 灵感库

灵感库收录与本研究相关的 **已证实理论、未证实理论、猜想和实验**。目的不是判断对错，而是从中筛选出可借鉴的思路、方法或类比。

## 收录原则

- 来源不限：主流理论、争议结果、历史上被否定的模型、其他领域的类比，都可以收录。
- 每条记录说明"它是什么"和"能借鉴什么"，两者分开写。
- 未证实或已被否定的内容，同样可能提供方法或视角上的启发。

## 评价指标

每条记录用以下指标打分（1–5 分）：

| 指标 | 含义 |
|---|---|
| 证据强度 | 实验或理论支持的程度（对应 [证据分级](../原则和方法/README.md#二证据分级) A–E） |
| 自洽性 | 理论内部是否自洽，与已确立物理是否相容 |
| 可检验性 | 现有或近期技术能否检验 |
| 相关度 | 与本项目目标的关联程度 |
| 启发性 | 能提供新视角、新方法或新类比的程度 |

> **重要**：指标只用于筛选和排序，**不决定是否借鉴**。证据强度低的猜想，也可能在方法或视角上很有价值；"启发性"一栏就是为此单独设置的。
