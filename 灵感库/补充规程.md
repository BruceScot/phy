# 灵感库补充规程

定时任务和手动补充都按本规程执行。规程可以随项目调整，调整后在文末记录。

## 每次运行

1. 阅读 `目标/README.md`、`我的想法/README.md`、`灵感库/索引.md`，了解当前方向和已有条目。
2. 按下表选择本次的 **来源侧重**（按运行当天星期几），在侧重之外也可以收录其他来源的高价值内容。
3. 新增 **3–5 条**。质量优先：宁可少收，也不要凑数。
4. 每条按 [模板.md](模板.md) 填写，编号顺延索引中的最大编号。
5. 运行 `python3 工具/生成索引.py` 更新索引。
6. 在 [补充日志.md](补充日志.md) 末尾追加一行：日期、侧重、新增编号、简短说明。
7. 提交并推送到 `main`。

## 来源轮换

| 星期 | 侧重 | 说明 |
|---|---|---|
| 一 | 前沿 | 近一年 arXiv、期刊上的新理论、新实验 |
| 二 | 经典 | 教科书级理论和关键实验中，尚未收录的部分 |
| 三 | 历史 | 已被取代或否定的理论、历史上的争论 |
| 四 | 前沿 | 同周一，偏重实验和争议结果 |
| 五 | 科普 | 科普文章、视频中的类比、图像和通俗说法 |
| 六 | 民科与边缘 | 非主流理论、民间猜想 |
| 日 | 交叉领域 | 凝聚态、光学、引力、信息论中可以类比的内容 |

## 选题优先级

1. 与 `目标/` 中的研究范围和 `我的想法/` 中的方向直接相关的内容。
2. 能和已有条目形成对照、补充或矛盾的内容。
3. 填补索引中标签覆盖较少的空白。

## 各类来源的处理

- **前沿**：用网络搜索确认论文存在，并核对作者、年份、编号；摘要中的结论与正文不一致时，以正文为准。
- **科普**：视频无法直接观看时，用标题、简介、文字稿或相关报道，并在录入字段中标"待核实"。重点提取类比和图像，同时指出类比在哪里失效。
- **民科与边缘**：忠实转述原说法，不嘲讽；在"依据与争议"中写清它与哪些已确立结果冲突；置信度通常为 1，但认真评估可参考性。
- **任何来源**：没有找到可靠出处的内容，录入字段标"待核实"，不要编造文献。

## 质量要求

- "可借鉴点"必须具体到可以直接拿去用的程度。
- 不重复收录：先按名称和标签检索索引；已有条目时，在原条目中补充新信息，并在日志中注明"更新 Lxxx"。
- 引用原文只摘短句，其余用自己的话概括。
