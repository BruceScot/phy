# 理论谱系

> 范围：量子真空，以及光子与电子的相互作用。各条目对应的灵感库编号见括号。

## 1. 经典与半经典层

- 爱因斯坦光电效应（光量子假说）、康普顿散射、汤姆逊散射。
- **半经典理论**：电子量子化、光场经典化。能解释大部分光电子实验，但无法自洽描述真空涨落、有限光速等涌现现象 [arXiv:2603.17582]。
- **随机电动力学**：经典电动力学加经典随机零点场，非主流（L006）。

## 2. 量子电动力学（QED）主线

- 狄拉克方程；Schwinger–Tomonaga–Feynman–Dyson 重整化 QED。
- 由电子与虚光子、真空涨落作用产生的效应：自发辐射、Lamb 位移、Casimir–Polder 相互作用、电子反常磁矩 [arXiv:2603.17582]。
- **真空极化**：虚正负电子对使真空可被极化，耦合常数随尺度跑动（L001）。
- **强场 QED**：Schwinger 临界场约 10¹⁶ V/cm，对应强度约 10²⁹ W/cm²；超过后真空不稳定，产生电子对 [arXiv:0812.3087]。
- **非线性真空**：Euler–Heisenberg 有效理论；光子–光子散射、真空双折射、光子分裂、Delbrück 散射（L004）。
- **强场微扰论的边界**：Ritus–Narozhny 猜想（L007）。

## 3. 真空涨落与零点能

- Casimir 效应、范德瓦尔斯与 Casimir–Polder 色散力（L002）[arXiv:1812.05078]。
- 动力学 Casimir 效应。
- Unruh 效应、Hawking 辐射（L005）。
- 真空应力张量涨落：真空辐射压涨落可对电子施加任意方向的力 [NSF PAR 10616273]。
- 解释层面：真空涨落图像与源场图像（L008）。

## 4. 光电子发射的时间域理论

- Eisenbud–Wigner–Smith 时间延迟（L003）。
- 阿秒 streaking、RABBITT 测量及其解析模型；测量延迟 = Wigner 延迟 + 连续–连续延迟 [arXiv:1205.6624]。
- 多体方法：RPA、R 矩阵、TDDFT [arXiv:1802.08619]。
- 固体：单步光电发射理论，计入体–真空界面散射、隐失通道 [arXiv:2603.08203]。

## 5. 腔 QED 与真空修饰物质

- 腔 QED：Purcell 效应、强耦合、极化激元。
- 非相对论 QED：Pauli–Fierz 哈密顿量；最小耦合与多极耦合 [arXiv:1812.05078]。
- QED 密度泛函、极化子化学。
- 腔量子材料：调控真空与热涨落以移动相边界（L010）[arXiv:2506.02170, arXiv:2604.08666]。
