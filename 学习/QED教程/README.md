# QED 系统教程

面向读者：**有高等数学和大学物理基础、非物理专业**，希望系统掌握量子电动力学（QED），并能读懂本项目涉及的研究文献。

## 一、这份教程能带你走到哪里

学完后你应当能够：

1. 读懂 QED 的拉氏量，知道每一项的物理意义；
2. 用费曼规则计算简单的散射截面（如 $e^+e^-\to\mu^+\mu^-$、康普顿散射）；
3. 理解圈图发散、重整化和跑动耦合常数，知道 Landau 极点从哪里来；
4. 看懂电子 g−2 的 Schwinger 项和 Lamb 位移的物理来源，并能做数量级估算；
5. 理解"真空涨落""虚粒子""零点能"在理论中的确切含义；
6. 读懂本项目灵感库中大部分条目所引用的原始论文。

**坦白说**：从大学物理到 QED，是物理专业本科高年级到研究生一年级的内容，通常需要 2–3 年的系统课程。本教程压缩了路径，但不会降低难度。最大的瓶颈通常不在 QED 本身，而在 **线性代数和量子力学**，这两部分不要跳过。

## 三、怎样使用

1. **按顺序学**。每章开头的"学习目标"是检验标准，达不到就不要往下走。
2. **每章必须动手推导**。看懂推导与能写出推导是两回事。建议准备一个专门的推导笔记本。
3. **习题先做再看答案**。答案折叠在 `<details>` 中，点开即见。
4. **每章末尾的"与本项目的联系"**把内容接到灵感库条目上，学完一章可以回去读相关条目，检验理解。
5. **遇到卡住的地方**，把问题写进 `我的想法/输入/`，或直接在对话中提出，我会写解答放到 `Claude想法/输出/`。
6. **配一本主教材**。本教程是导读与骨架，主教材提供完整细节和更多习题，见下文推荐。

## 四、符号约定

全教程统一采用粒子物理的标准约定（与 Peskin & Schroeder 一致）：

| 内容 | 约定 |
|---|---|
| 单位 | 从第 7 章起用自然单位 $\hbar=c=1$；前六章保留 $\hbar$、$c$ |
| 度规 | $\eta_{\mu\nu}=\mathrm{diag}(+1,-1,-1,-1)$ |
| 指标 | 希腊字母 $\mu,\nu=0,1,2,3$；拉丁字母 $i,j=1,2,3$；重复指标求和 |
| 电磁单位 | Heaviside–Lorentz 有理化单位，精细结构常数 $\alpha=e^2/4\pi\approx1/137$ |
| 电子电荷 | 记为 $e$，取 $e<0$（电子带负电），与 Peskin & Schroeder 相同 |
| 四动量 | $p^\mu=(E,\mathbf p)$，$p^2=E^2-|\mathbf p|^2=m^2$ |
| 狄拉克伴随 | $\bar\psi=\psi^\dagger\gamma^0$；斜杠记号 $\not p=\gamma^\mu p_\mu$ |

自然单位下常用的换算：$\hbar c\approx197.3\ \mathrm{MeV\cdot fm}$；$1\ \mathrm{GeV}^{-2}\approx0.3894\ \mathrm{mb}$；电子质量 $m_e\approx0.511$ MeV。

## 六、阶段自测

每完成一个阶段，试着不看书回答：

- **阶段一**：写出协变形式的麦克斯韦方程；从 $\mathcal L=\frac12\partial_\mu\phi\partial^\mu\phi-\frac12m^2\phi^2$ 推出运动方程；说明诺特定理的内容。
- **阶段二**：用 $a,a^\dagger$ 求谐振子能谱；写出泡利矩阵和它们的对易关系；推导费米黄金规则。
- **阶段三**：解释为什么零点能发散、什么是正规排序；写出光子的两个极化；说明为什么狄拉克场必须用反对易关系。
- **阶段四**：写出 QED 的费曼规则；说出真空极化如何使耦合常数随能量变化；估算 $a_e$ 的一阶值和氢 2S 的 Lamb 位移。
