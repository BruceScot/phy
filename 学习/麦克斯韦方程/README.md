# 麦克斯韦方程教程

面向读者：有高等数学和大学物理基础。目标是从零掌握麦克斯韦方程组，并能回答一个具体问题：**电磁波在真空中是怎样传播的，一个周期内的每个阶段发生了什么。** 这个问题的完整回答在 [第 7 章](07-一个周期内的传播形态.md)，配有可以拖动相位的交互演示。

本教程用 **国际单位制**（SI），与大学物理教材一致。学完后再读 [QED 教程](../QED教程/README.md) 第 2 章，会看到同样的方程如何写成四维协变形式。

## 方程组一览

学完后应当能够默写，并说出每一条的物理意义：

| 名称 | 微分形式 | 积分形式 | 含义 |
|---|---|---|---|
| 高斯定律 | $\nabla\cdot\mathbf E=\dfrac{\rho}{\epsilon_0}$ | $\oint\mathbf E\cdot d\mathbf A=\dfrac{Q}{\epsilon_0}$ | 电荷是电场线的源 |
| 无磁单极 | $\nabla\cdot\mathbf B=0$ | $\oint\mathbf B\cdot d\mathbf A=0$ | 磁场线没有起点和终点 |
| 法拉第定律 | $\nabla\times\mathbf E=-\dfrac{\partial\mathbf B}{\partial t}$ | $\oint\mathbf E\cdot d\mathbf l=-\dfrac{d\Phi_B}{dt}$ | 变化的磁场产生涡旋电场 |
| 安培–麦克斯韦定律 | $\nabla\times\mathbf B=\mu_0\mathbf J+\mu_0\epsilon_0\dfrac{\partial\mathbf E}{\partial t}$ | $\oint\mathbf B\cdot d\mathbf l=\mu_0I+\mu_0\epsilon_0\dfrac{d\Phi_E}{dt}$ | 电流和变化的电场产生涡旋磁场 |

加上洛伦兹力 $\mathbf F=q(\mathbf E+\mathbf v\times\mathbf B)$，就构成了全部经典电磁学。
