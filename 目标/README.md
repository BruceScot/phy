# 目标

> 状态：**草稿，待作者确认。** 本页记录作者的研究目标和感兴趣的范围，也是最终理论希望覆盖的范围。以下内容由 Claude 根据前期对话起草，作者修改后以作者版本为准。

## 一、研究目标

1. 理解量子真空的本质：真空是什么，它的"涨落"在什么意义上是真实的。
2. 理解光子与电子相互作用的完整图景：从单光子过程到强场，从频域到时域，从自由空间到结构化环境。
3. 找出现有理论与实验之间的矛盾和空白，并尝试构建能够解释它们的理论。
4. 探索量子力学和 QED 之下更底层的理论：它在已检验范围内重现 QED，就像广义相对论重现牛顿引力，但理论基础和模型可以不同（见 [M001](../我的想法/README.md)）。

## 三、最终理论希望覆盖的范围

- **必须覆盖**：上表中的现象，并在已被精密检验的区域内与 QED 的结果一致（见 [原则](../原则/README.md) 第 3 条）。
- **希望解释**：背景中列出的矛盾点与未知点中，至少有一类得到新的理解或可检验的预言。
- **暂不覆盖**：强相互作用和弱相互作用的细节；等级问题（L018）和中微子质量（L019）只作为背景参考。量子引力只在与真空能、底层理论相关的范围内涉及。
