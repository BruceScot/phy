# 原则和方法

## 一、研究原则

1. **区分事实、解释与猜想**：同一现象可能有多种解释（如 Casimir 效应的真空涨落解释与源场解释），记录时要分开写。
2. **每个论断有出处**：没有出处的内容标注"待核实"，不能直接写入背景。
3. **保留矛盾**：理论与实验不符时，记录双方数据和各自的假设，不急于下结论。
4. **开放收集，审慎采用**：灵感库可以收录未证实甚至边缘的想法；写入背景和结论时才严格要求证据。
5. **可检验优先**：最终的研究问题必须对应具体可观测量。

## 二、证据分级

| 等级 | 含义 | 例子 |
|---|---|---|
| A 已确立 | 多个独立实验高精度验证，理论自洽 | Lamb 位移、电子反常磁矩的 QED 计算 |
| B 有证据 | 有实验支持，但精度、重复性或解释仍有争议 | 腔中真空涨落修饰材料性质 |
| C 有理论 | 理论推导自洽，尚无直接实验验证 | 光子–光子弹性散射（低能区）、真空双折射 |
| D 猜想 | 有动机或类比，推导不完整 | 强场下微扰展开失效（Ritus–Narozhny 猜想） |
| E 存疑 | 与主流结果冲突，或方法有明显问题 | — |

## 三、工作流程

1. **收集**：新材料按 [灵感库模板](../灵感库/模板.md) 录入。
2. **核实**：查原始文献，确认数据、条件与结论，更新证据等级。
3. **提炼**：把与目标相关的要点写入 `背景/`，注明引用。
4. **评估**：定期回顾灵感库，按指标排序，但不以指标作为唯一取舍依据。
5. **成形**：选定方向后，在 `目标/` 中写明研究问题。

## 四、引用规范

- 优先引用原始论文、综述、权威机构报告；尽量少用二手转述。
- 文中用 `[作者 年份]` 或 arXiv 编号引用，完整条目放入 `参考文献/references.bib`。
- 引用原文时只摘短句，其余用自己的话概括。
