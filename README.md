# 真空与光子–电子相互作用研究

本仓库用于持续积累和整理"量子真空"与"光子–电子相互作用"方向的研究材料，作为后续研究与交互的工作区。

## 术语界定

- **真空**：指量子真空（QED 真空、电磁零点场、虚粒子涨落），而非工程意义上的低压环境。
- **光子–电子**：指光与电子的相互作用，包括光电效应与光电子发射、散射、辐射、强场过程，以及腔中光与物质的耦合。

## 使用方式

1. 新材料先进 **灵感库**，按模板填写，不必先判断其对错。
2. 经过核实、与目标直接相关的内容，提炼后写入 **背景**。
3. 方法与判断标准的变化记录在 **原则和方法**。
4. 目标调整时更新 **目标**，并注明日期和原因。
