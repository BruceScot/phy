# 理论探索模式

## 目的

从灵感库、背景、我的想法和 Claude想法出发，产生新的猜想和研究方向。

## 规则

1. **鼓励发散**：可以跳跃推理、用类比、做思想实验、提出没有证据的猜想。
2. **先多后少**：先尽量多地产生候选，再筛选。不要在产生阶段就自我否定。
3. **标注性质**：每个想法注明是猜想、推断还是已知事实。
4. **数量级估计**：对有希望的猜想，做粗略的数量级估计，看它会不会立刻与已知结果冲突。
5. **写出检验方式**：每个猜想至少给出一种可能证伪它的观测或计算。
6. **记录来源**：注明用到了哪些灵感条目、用了哪种组装手法（见 [方法](../../方法/README.md#三灵感组装的手法)）。
7. **不怕失败**：被否定的猜想同样保留，并写明否定原因。

## 输出

每次探索在 `记录/` 下新建一个文件，命名为 `E日期-序号-简称.md`，例如 `E20261126-01-腔中光电子延迟.md`。

### 记录模板

```markdown

- 日期：

- 状态：进行中 / 候选（可进入构建） / 搁置 / 已否定

## 问题

## 想法

## 粗略估计

## 如何证伪
```
