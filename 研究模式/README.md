# 研究模式

项目分为两种工作模式。每次工作开始时，先说明处于哪种模式；作者也可以直接指定。

| | 理论探索 | 理论构建 |
|---|---|---|
| 目的 | 产生新想法、新猜想、新方向 | 把选中的猜想变成严格的理论 |
| 思维方式 | 发散、联想、大胆猜测 | 收敛、严格、步步可查 |
| 主要输入 | 灵感库、背景、我的想法、Claude想法 | 探索阶段选出的猜想 |
| 允许 | 跳跃推理、不完整论证、类比、思想实验、数量级估计 | 只允许有依据的推导和计算 |
| 输出 | 探索记录：猜想、候选方向、粗略估计 | 推导文档、计算代码、定量预言 |
| 标准 | 是否新颖、是否可能可检验、是否值得深入 | 是否自洽、是否通过检验、结论是否可复现 |
| 详细规则 | [理论探索/](理论探索/README.md) | [理论构建/](理论构建/README.md) |

## 模式之间的转换

- **探索 → 构建**：一个猜想满足以下条件时，可以进入构建：
  1. 能写出明确的数学表述或模型；
  2. 至少有一个可观测量或可计算量；
  3. 粗略估计没有立刻与已知结果冲突；
  4. 作者同意投入构建。
- **构建 → 探索**：构建中出现以下情况时，回到探索：
  1. 推导中发现矛盾或需要新的假设；
  2. 计算结果与已知数据冲突；
  3. 构建中冒出新的问题或方向。

返回探索时，在构建文档中写明原因，并在探索记录中开一条新记录。
