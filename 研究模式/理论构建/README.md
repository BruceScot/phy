# 理论构建模式

## 目的

对探索阶段选出的猜想，进行严格的理论推导和数学计算，给出自洽的表述和定量预言。

## 规则

1. **从明确的出发点开始**：写清楚假设、拉氏量或哈密顿量、近似条件、符号约定与单位制。
2. **每一步可查**：推导步骤完整，不跳步；引用已知结果时注明出处。
3. **必须通过检验**：量纲、极限、已知结果复现、独立验证（见 [方法](../../方法/README.md#五推导与计算的检验)）。
4. **计算可复现**：数值或符号计算的代码放在课题目录下，写明依赖和运行方式；优先用 Python（NumPy、SciPy、SymPy）。
5. **区分结果与解释**：数学结果与它的物理解释分开写。
6. **不确定就停下**：推导中遇到无法确定的步骤，明确标出，不要用含糊的说法跳过。
7. **发现问题就回到探索**：构建中出现的矛盾或新方向，按 [研究模式](../README.md#模式之间的转换) 的规则转回探索。

## 输出

每个课题在本目录下建一个子目录，命名为 `T序号-简称/`，例如 `T01-腔中光电子延迟/`，其中包括：

- `README.md`：课题说明、来源（对应的探索记录）、当前状态、主要结论；
- `推导.md`：完整推导，数学公式用 LaTeX；
- `计算/`：代码与输出；
- `检验.md`：各项检验的结果。
