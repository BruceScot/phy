# 原则

原则是指导整个研究的哲学和宏观逻辑判断。它回答"什么样的理论是好的、什么样的结论可以接受"，而不规定具体怎么做（具体做法见 [方法](../方法/README.md)）。

> 状态：初稿。作者可以随时增删，增删时在文末记录。

## 1. 实验是最终裁判

理论的价值最终由它与观测的符合程度决定。数学上的优美、图像上的直观，都不能替代实验检验。

## 2. 可证伪

一个理论如果在任何可能的观测下都不会出错，它就没有说出关于世界的任何东西。每一个猜想最终都要回答：**什么样的观测结果会证明它是错的？**

## 3. 对应原理：尊重已被检验的精度

新理论在已被验证的区域内必须还原为旧理论。以电子 g 因子计，QED 的预言与实验符合到约 10⁻¹² 的相对精度（精度目前受精细结构常数测定的限制），任何关于真空和光子–电子相互作用的新理论，都必须在这一精度内重现 QED 的结果。新物理只能出现在尚未被检验的地方：极端场强、极短时间、结构化环境、非微扰区，或者诠释层面。

## 4. 区分现象、数学与图像

同一个可观测结果，可能对应不同的数学形式，不同的数学形式又可能对应不同的物理图像（例如真空涨落图像与源场图像，见 L008）。**先确认分歧是在现象、数学还是图像层面**，再判断它是否有物理意义。

## 5. 有效理论观

每个理论都有适用的尺度和条件。与其问"哪个理论是对的"，不如问"它在哪个范围内有效，在哪里失效，失效时由什么接替"。理论失效的边界，往往是新物理所在。

## 6. 对称性与守恒律优先

对称性和守恒律是最可靠的约束。违反 Lorentz 不变性、规范不变性、因果性或能量守恒的猜想，需要极强的理由。

## 7. 简约，但不过早简化

在解释力相同时选择更简单的理论（奥卡姆剃刀）。但不能为了简单而丢掉尚未解释的数据或矛盾。

## 8. 开放与怀疑并存

对任何来源的想法保持开放，包括非主流和民科；对任何结论保持怀疑，包括自己的。开放体现在收集和探索阶段，怀疑体现在构建和检验阶段。

## 9. 矛盾是线索

理论与实验的矛盾，或两种理论之间的矛盾，不是需要回避的麻烦，而是研究最有价值的入口。记录矛盾时保留双方的全部信息，不急于选边。
